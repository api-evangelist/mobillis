# Mobillis

> Mobillis (operated by Reflex Mobility, Inc.) is a fintech mobility platform that turns vehicle fleet inventory into a prepaid billing and access product. It overlays legacy rental/fleet systems so operators collect payment upfront and reach "everyday driver" segments, and lets distribution partners resell vehicle access via referral links, a white-label front end, or the Mobillis Open APIs (wallets, top-ups, ledger, webhooks). Operates from Johannesburg and New York.

## API

- [Mobillis Open API](https://mobillis.com/#api): Partner-gated REST API — wallet creation/management, PSP-orchestrated top-ups, ledger/transaction history, and webhook registration. Contact partners@mobillis.com for access.

Documented operations:
- POST /v1/wallets — create a wallet
- POST /v1/wallets/:id/topup — top up a wallet balance
- GET /v1/wallets/:id/ledger — read wallet ledger / transactions
- POST /v1/webhooks — register a webhook subscription
- GET /r/{brand}?via=mobillis — branded referral link (revenue share on top-ups)

## Webhooks

- wallet.low_balance — low-balance alert
- wallet.billing — billing trigger
